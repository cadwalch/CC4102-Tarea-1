# Resultados crudos

Esta carpeta almacena los archivos CSV generados al ejecutar los experimentos.

Los archivos de resultados no se incluyen en el repositorio porque pueden ocupar varios GB.
La carpeta se mantiene versionada únicamente para conservar la estructura esperada del proyecto.

Los resultados se generan automáticamente al ejecutar, por ejemplo:

```bash
./bin/main --all
```

o mediante los targets correspondientes del `Makefile`.
